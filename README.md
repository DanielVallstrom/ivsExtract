# ivsExtract

Extracts data from CSV files in IVS (Integrated Values Surveys) format.

The program processes data from the European Values Study (EVS) and the World Values Survey (WVS).

## Building

```bash
make
```

## Usage

```bash
./ivsExtract --help
```

## Paper

This program was used to generate results in:
[https://arxiv.org/abs/2404.03685](https://arxiv.org/abs/2404.03685)
